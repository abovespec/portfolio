Percentage decrease tells you how much a value has fallen relative to its original amount. Sales discounts, budget cuts, weight loss, declining test scores — all of these involve the same underlying calculation.

## The percentage decrease formula

```
Percentage Decrease = ((Original Value − New Value) / Original Value) × 100
```

Notice the subtraction order is flipped compared to percentage increase: here you subtract the new (lower) value from the original. The result is always expressed as a positive number representing how much the value dropped.

For more on this topic, see [*Percentage Difference vs. Percentage Change: What's the Difference?*](/blog/percentage-difference-vs-change).

## Step-by-step worked examples

### Example 1 — Sale price discount

A jacket was originally priced at $180. It is now on sale for $135. What is the percentage decrease in price?

1. Subtract new from original: $180 − $135 = $45
2. Divide by original: $45 / $180 = 0.25
3. Multiply by 100: 0.25 × 100 = **25%**

The price decreased by 25%.

### Example 2 — Reduced calorie intake

A person consumed 2,400 calories per day. After changing their diet they now consume 1,980 calories. What percentage decrease is that?

1. 2,400 − 1,980 = 420
2. 420 / 2,400 = 0.175
3. 0.175 × 100 = **17.5%**

Calorie intake decreased by 17.5%.

### Example 3 — Company revenue decline

A store brought in $94,000 in revenue in Q3. In Q4 revenue fell to $79,900. What was the percentage decrease?

1. $94,000 − $79,900 = $14,100
2. $14,100 / $94,000 = 0.15
3. 0.15 × 100 = **15%**

Revenue decreased by 15%.

### Example 4 — Finding the new value after a known percentage decrease

A car worth $28,000 depreciates by 18% in its first year. What is it worth after one year?

```
Amount of decrease = 18% × $28,000 = 0.18 × 28,000 = $5,040
New value = $28,000 − $5,040 = $22,960
```

Or more directly: multiply the original by `(1 − 0.18) = 0.82`:

```
$28,000 × 0.82 = $22,960
```

### Example 5 — Working backwards from the percentage

An item now costs $68 after a 15% price reduction. What was the original price?

A 15% decrease means the current price is 85% of the original:

```
Original = New Value / (1 − Percentage Decrease / 100)
Original = $68 / 0.85 = $80
```

The original price was $80.

## The unified percentage change formula

Percentage decrease is just a negative percentage change. The same formula handles both increase and decrease:

For more on this topic, see [*Percentage Change Formula: How to Calculate Increase and Decrease*](/blog/percentage-change-formula).

```
Percentage Change = ((New Value − Original Value) / Original Value) × 100
```

- A positive result = increase
- A negative result = decrease

Using this version, you never need to worry about which order to subtract — the sign of the answer tells you the direction.

## Common mistakes

**Dividing by the new value instead of the original.** The base of the calculation is always where you started, not where you ended up. If a price dropped from $200 to $150, dividing by $150 (the new value) gives 33.3% — which is wrong. The correct answer is `50 / 200 × 100 = 25%`.

**Confusing percentage decrease with percentage points.** If a store's profit margin drops from 22% to 18%, the drop is 4 *percentage points*. But as a percentage of the original margin, the decrease is `(4 / 22) × 100 = 18.2%`. These are very different figures.

**Assuming decreases are symmetrical with increases.** A 50% decrease followed by a 50% increase does not return you to the original value. Start at $100, decrease by 50% to get $50, then increase by 50% to get $75 — not $100. Percentage changes are always relative to the current base.

## Practical use cases

**Retail discounts:** Stores advertise percentage-off sales. Knowing the formula lets you verify the marked discount and calculate the final price mentally.

For more on this topic, see [*How to Calculate Percentage Increase: Formula and Step-by-Step Guide*](/blog/how-to-calculate-percentage-increase).

**Depreciation:** Assets like cars, computers, and machinery lose value over time. Accountants express this as a percentage decrease per year.

**Health and fitness:** Weight, body fat percentage, resting heart rate — tracking these as percentage decreases gives a normalised measure that works across different body sizes.

**Budget reductions:** Organisations cut budgets by percentage. A department with a $420,000 budget facing a 12% cut loses $50,400 and has $369,600 remaining.

**Economic indicators:** GDP contraction, unemployment rate changes, and inflation adjustments are all expressed as percentage changes.
