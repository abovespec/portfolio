Percentage increase measures how much a value has grown relative to its original amount. Whether you are tracking a salary raise, a product price going up, or a population growing, the calculation is always the same.

## The percentage increase formula

```
Percentage Increase = ((New Value − Original Value) / Original Value) × 100
```

The result tells you how much the value grew as a percentage of where it started. A positive result means growth; if your answer comes out negative, the value actually decreased — that is a percentage decrease, not an increase.

## Step-by-step worked examples

### Example 1 — Salary raise

Your salary was $52,000 last year. This year it is $56,160. What percentage raise did you receive?

1. Subtract the original from the new value: $56,160 − $52,000 = $4,160
2. Divide by the original: $4,160 / $52,000 = 0.08
3. Multiply by 100: 0.08 × 100 = **8%**

You received an 8% raise.

### Example 2 — Product price increase

A grocery item cost $2.40 last month. It now costs $2.76. By what percentage did the price increase?

1. $2.76 − $2.40 = $0.36
2. $0.36 / $2.40 = 0.15
3. 0.15 × 100 = **15%**

The price increased by 15%.

### Example 3 — Website traffic

A website received 8,400 visits in March and 11,340 in April. What was the percentage increase in traffic?

1. 11,340 − 8,400 = 2,940
2. 2,940 / 8,400 = 0.35
3. 0.35 × 100 = **35%**

Traffic grew by 35%.

### Example 4 — Working backwards from the percentage

A product costs $130 after a 30% price increase. What was the original price?

When a value increases by 30%, the new value equals 130% of the original:

```
Original = New Value / (1 + Percentage Increase / 100)
Original = 130 / 1.30 = $100
```

The original price was $100.

## Common mistakes

**Using the new value as the base.** The denominator in the formula is always the *original* value — the starting point. Dividing by the new value gives you a different (and incorrect) result.

**Forgetting to multiply by 100.** The formula gives you a decimal. You need to multiply by 100 to express it as a percentage. 0.08 is not a percentage — 8% is.

**Chaining percentage increases incorrectly.** Two consecutive 10% increases do not equal a 20% total increase. After the first 10% increase, the new base is higher, so the second 10% is applied to a larger number.

- Start: $100
- After 10% increase: $110
- After another 10% increase: $110 × 1.10 = $121
- Total increase: 21%, not 20%

To find the combined effect of two percentage increases, multiply the multipliers:

```
1.10 × 1.10 = 1.21 → 21% total increase
```

## Percentage increase vs. absolute increase

A percentage increase tells you *relative* growth. An absolute increase tells you the raw difference. Both are useful, but they tell different stories.

For more on this topic, see [*Percentage Difference vs. Percentage Change: What's the Difference?*](/blog/percentage-difference-vs-change).

A company's revenue growing from $1,000,000 to $1,100,000 is:
- Absolute increase: $100,000
- Percentage increase: 10%

A small startup's revenue growing from $5,000 to $5,500 is:
- Absolute increase: $500
- Percentage increase: 10%

Both grew by the same percentage, but the dollar amounts are vastly different. Always consider which measure is more meaningful for the context.

## Real-world applications

**Inflation:** Government agencies track price increases as percentages to show how purchasing power changes over time.

**Investment returns:** A stock that rises from $45 to $54 has gained `(54 − 45) / 45 × 100 = 20%`. This lets you compare returns across investments of different sizes.

**Population growth:** Demographers express population change as a percentage to compare cities, countries, and regions of different sizes on equal footing.

**Performance metrics:** Business dashboards almost always show metrics as percentage changes — revenue up 12%, conversion rate up 3%, churn down 5%.

## Quick reference: common multipliers

If you need to apply a percentage increase directly to a value, use these multipliers (original × multiplier = new value):

| Increase | Multiplier |
|----------|------------|
| 5% | 1.05 |
| 10% | 1.10 |
| 15% | 1.15 |
| 20% | 1.20 |
| 25% | 1.25 |
| 50% | 1.50 |
| 100% | 2.00 |
