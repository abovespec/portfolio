## Percent Difference Calculator — Compare Two Values Without Direction

### The Formula

**Percent Difference = (|A − B| / ((|A| + |B|) / 2)) × 100**

Both values are treated equally — swapping A and B gives the same result.

### When to Use This

Use **percent difference** when neither value is a "reference" or "original." Use **percent change** when there is a clear before/after.

### Example

Lab Test A: 80 units. Lab Test B: 100 units.

|A − B| = 20. Average = 90. Percent difference = (20 / 90) × 100 ≈ **22.2%**.

Note: percent change from 80→100 is 25%, but percent *difference* between 80 and 100 is 22.2%.
