Google Docs has a built-in word count tool that shows words, characters, pages, and more. Here's how to access it in every way available.

## Menu method

**Tools → Word count** (or **Tools → Word count** on Mac)

For more on this topic, see [*Flesch-Kincaid Readability Score: What It Means and How to Improve It*](/blog/flesch-kincaid-readability).

This opens the Word Count dialog showing:
- Pages
- Words
- Characters (without spaces)
- Characters (with spaces)

For more on this topic, see [*How Many Words Is a Novel? Genre-by-Genre Word Count Guide*](/blog/how-many-words-in-a-novel).

Click **OK** to close it.

## Keyboard shortcut

| Platform | Shortcut |
|----------|----------|
| Windows / Linux | `Ctrl + Shift + C` |
| Mac | `Cmd + Shift + C` |

This opens the same Word Count dialog instantly.

## Live word count in the toolbar

You can display a live word count at the bottom of the screen while you type:

1. Open **Tools → Word count**
2. Check **Display word count while typing**
3. Click **OK**

A small word count badge appears in the bottom-left corner of your document. Click it to toggle between words, characters, and pages.

## Counting a selection

To check the word count of a specific section:

1. Select the text you want to count
2. Open the word count dialog (`Ctrl+Shift+C` or `Cmd+Shift+C`)

The dialog shows counts for the selection only. This is useful for checking the length of a single paragraph, section, or argument when you have a target length requirement.

## What counts as a word?

Google Docs uses standard word-boundary rules: sequences of characters separated by spaces or punctuation. Hyphenated words like "well-known" count as one word. Numbers count as words. URLs usually count as one word regardless of length.

## What doesn't show up in word count?

- **Headers and footers** — text in headers and footers is excluded from the word count
- **Comments** — comment text in the sidebar is excluded
- **Text in text boxes or drawings** — not counted

If your document uses headers/footers heavily (like a formatted academic paper), the word count may be lower than your actual target. Paste into a plain text editor or use an online word counter to get a count that includes all visible text.

## Counting words in Google Docs on mobile

The Google Docs mobile app doesn't show the word count in the toolbar by default:

**Android:** Tap the three-dot menu (⋮) → **Word count**

**iOS:** Tap the three-dot menu → **Word count**

The mobile count shows words and characters, matching the desktop view.

## Comparing word count with Google Docs vs. other tools

Google Docs and Microsoft Word may show slightly different counts for the same document. Common reasons:

- **Footnotes** — Word counts footnotes by default; Docs does not always
- **Hyphenated words** — Different tokenization rules
- **Numbers and symbols** — Handling varies

For consistency in academic submission, check your target institution's instructions — some specify "words as counted by Microsoft Word" or similar.
