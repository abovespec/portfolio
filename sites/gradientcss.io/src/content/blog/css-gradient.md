CSS gradients let you create smooth transitions between colors without images. They're generated by the browser at any resolution, making them sharp on retina displays and fast to load. There are three types: `linear-gradient`, `radial-gradient`, and `conic-gradient`.

## linear-gradient

Transitions colors in a straight line.

**Basic syntax:**

```css
background: linear-gradient(direction, color1, color2, ...);
```

**Direction examples:**

```css
/* Top to bottom (default) */
background: linear-gradient(#e66465, #9198e5);

/* Left to right */
background: linear-gradient(to right, #e66465, #9198e5);

/* Diagonal: top-left to bottom-right */
background: linear-gradient(to bottom right, #e66465, #9198e5);

/* Angle in degrees */
background: linear-gradient(135deg, #e66465, #9198e5);
```

**Color stops:**

```css
/* Three colors, evenly distributed */
background: linear-gradient(to right, #f00, #0f0, #00f);

/* Custom stop positions */
background: linear-gradient(to right,
  #f00 0%,
  #ff0 30%,
  #0f0 70%,
  #00f 100%
);

/* Hard stop (no transition) */
background: linear-gradient(to right,
  #e66465 50%,
  #9198e5 50%
);
```

## radial-gradient

Radiates outward from a center point.

```css
/* Default: ellipse, centered */
background: radial-gradient(#e66465, #9198e5);

/* Circle */
background: radial-gradient(circle, #e66465, #9198e5);

/* Ellipse with size */
background: radial-gradient(ellipse 80% 50% at center, #e66465, #9198e5);

/* Custom center position */
background: radial-gradient(circle at 20% 80%, #e66465, #9198e5);

/* Circle at top-left */
background: radial-gradient(circle at top left, #f00, transparent);
```

**Size keywords:**

```css
/* closest-side: edge at the nearest side */
background: radial-gradient(circle closest-side at 20% 50%, #e66465, #9198e5);

/* farthest-corner (default for ellipse) */
background: radial-gradient(ellipse farthest-corner at center, #e66465, #9198e5);
```

## conic-gradient

Transitions colors around a center point (like a color wheel or pie chart).

```css
/* Basic conic gradient */
background: conic-gradient(#e66465, #9198e5, #e66465);

/* From a specific angle */
background: conic-gradient(from 45deg, #f00, #0f0, #00f, #f00);

/* From a specific angle, at a specific position */
background: conic-gradient(from 45deg at 30% 50%, #f00, #0f0, #00f, #f00);

/* Pie chart: 30% red, 70% blue */
background: conic-gradient(red 30%, blue 0%);

/* Three segments */
background: conic-gradient(
  red 0% 33%,
  green 33% 66%,
  blue 66% 100%
);
```

## Transparency in gradients

Use `transparent` or `rgba()` to fade to nothing:

```css
/* Fade from color to transparent */
background: linear-gradient(to bottom, rgba(0, 0, 0, 0.7), transparent);

/* Dark overlay on an image */
.hero {
  background-image:
    linear-gradient(to bottom, rgba(0,0,0,0) 0%, rgba(0,0,0,0.7) 100%),
    url('/hero.jpg');
  background-size: cover;
}

/* Fade out on the right edge */
background: linear-gradient(to right, #fff 80%, transparent);
```

## Repeating gradients

```css
/* Repeating linear */
background: repeating-linear-gradient(
  45deg,
  #e66465 0px,
  #e66465 10px,
  #9198e5 10px,
  #9198e5 20px
);

/* Repeating radial (concentric rings) */
background: repeating-radial-gradient(
  circle,
  #e66465 0px,
  #e66465 10px,
  #9198e5 10px,
  #9198e5 20px
);
```

## Multiple gradients (layers)

CSS backgrounds support multiple layers separated by commas. Layers are painted front-to-back:

```css
background:
  linear-gradient(to right, rgba(255,0,0,0.5), rgba(0,0,255,0.5)),
  radial-gradient(circle at center, #fff, #000);
```

## Browser support

All three gradient types are supported in all modern browsers. For production, you no longer need `-webkit-` prefixes for `linear-gradient` and `radial-gradient`.

`conic-gradient` requires Chrome 69+, Safari 12.1+, Firefox 83+. Check [caniuse.com](https://caniuse.com/css-conic-gradients) for the latest.
