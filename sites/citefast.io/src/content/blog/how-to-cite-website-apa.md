Websites are the trickiest sources to cite in APA because they vary so widely. Some have named authors; others are written by organizations. Some have clear publication dates; many do not. Some are stable government pages; others are blog posts that can disappear tomorrow. APA 7th edition (2020) provides clear rules for all of these situations — but you need to know which rule applies to which source.

This guide covers every common website type you are likely to cite, with templates and multiple real examples for each.

## The core APA 7 website template

```
Author, A. A. (Year, Month Day). Title of page. Website Name. URL
```

Five elements, in order:

1. **Author** — Last name, initials. For an organization, write the full name.
2. **Date** — Year, then Month Day in parentheses: `(2025, March 18)`. If there's only a year, use `(2025)`.
3. **Title** — The specific page title in italics, sentence case.
4. **Website name** — The name of the site (not the URL). Omit if it is the same as the author.
5. **URL** — Full URL, no period at the very end (because it could be misread as part of the link), though APA's own examples do include a period — follow your instructor's preference.

## Basic webpage with author and date

This is the simplest case: a named person wrote the page and a date is visible.

**Template:**
```
Last, F. M. (Year, Month Day). Title of page. Website Name. URL
```

**Example:**
```
Roberts, J. (2025, November 12). How neural networks learn. Towards Data Science. https://towardsdatascience.com/how-neural-networks-learn
```

**In-text citation:**
```
(Roberts, 2025)
```

For a direct quote, add a page number or paragraph number. Web pages have no page numbers, so use paragraph numbering:
```
(Roberts, 2025, para. 4)
```

## Webpage with an organization as author

When a government agency, nonprofit, corporation, or other organization is responsible for the content and there is no individually named author, use the organization name as the author.

**Example — government agency:**
```
Centers for Disease Control and Prevention. (2024, September 6). About COVID-19. https://www.cdc.gov/covid/about/index.html
```

**Example — nonprofit:**
```
World Health Organization. (2026, January 20). Mental health fact sheet. https://www.who.int/news-room/fact-sheets/detail/mental-health
```

**Example — company:**
```
Apple. (2025, October 14). Environmental progress report. Apple Newsroom. https://www.apple.com/newsroom/2025/10/environmental-progress-report/
```

**In-text citations:**
```
(Centers for Disease Control and Prevention, 2024)
(World Health Organization, 2026)
(Apple, 2025)
```

After the first mention, you may abbreviate a long organization name:
```
First mention: (Centers for Disease Control and Prevention [CDC], 2024)
Subsequent mentions: (CDC, 2024)
```

Note: If the website name and the author name are the same, omit the website name to avoid redundancy.

**Without website name (same as author):**
```
World Health Organization. (2026, January 20). Mental health fact sheet. https://www.who.int/news-room/fact-sheets/detail/mental-health
```

## Webpage with no author

If no individual or organization is identified as the author, begin the citation with the title of the page.

**Template:**
```
Title of page. (Year, Month Day). Website Name. URL
```

**Example:**
```
Global chip shortage explained. (2026, March 3). BBC News. https://www.bbc.com/news/technology-56252495
```

**In-text citation** — use a shortened version of the title in quotation marks:
```
("Global Chip Shortage," 2026)
```

Use enough words from the title to lead the reader to the correct entry in the reference list, typically the first few words.

## Webpage with no date

Many websites do not display a clear publication or update date. In APA, use `(n.d.)` in place of the date.

**Template:**
```
Author, A. A. (n.d.). Title of page. Website Name. URL
```

**Example:**
```
Smith, B. (n.d.). Introduction to SQL indexing. Database Weekly. https://dbweekly.com/sql-indexing
```

**Example — organization, no date:**
```
National Institutes of Health. (n.d.). How clinical trials work. https://www.nih.gov/health-information/nih-clinical-research-trials-you/how-clinical-trials-work
```

**In-text citation:**
```
(Smith, n.d.)
(National Institutes of Health, n.d.)
```

## Webpage that changes over time (living documents, wikis)

For sources that are updated continuously — like Wikipedia articles, wiki pages, or government databases — add a retrieval date, because the content may have changed by the time a reader visits.

**Template:**
```
Author or Organization. (Year, Month Day). Title. Website Name. Retrieved Month Day, Year, from URL
```

**Wikipedia example:**
```
Citation. (2026, May 30). In Wikipedia. Retrieved June 7, 2026, from https://en.wikipedia.org/wiki/Citation
```

**In-text citation:**
```
("Citation," 2026)
```

Wikipedia is generally not acceptable as a scholarly source, but this is the correct format if you are permitted to cite it.

## Blog posts

Blog posts are cited like webpages, but you identify the platform (or blog name) as the website name.

**Example — named author:**
```
Kolowich, S. (2025, August 22). Why students are still failing at citations. The Chronicle of Higher Education. https://www.chronicle.com/article/why-students-fail-citations
```

**Example — organizational blog:**
```
American Psychological Association. (2025, April 15). New guidance on inclusive language in research. APA News. https://www.apa.org/news/press/releases/2025/04/inclusive-language
```

**In-text citations:**
```
(Kolowich, 2025)
(American Psychological Association, 2025)
```

## Online news articles

Online news articles follow the same format as webpages. The news outlet is the website name.

**Example:**
```
Metz, C. (2026, February 3). The A.I. race is accelerating — here's what that means for you. The New York Times. https://www.nytimes.com/2026/02/03/technology/ai-race-accelerating.html
```

**Example — no author (news wire or unsigned editorial):**
```
Tech layoffs hit a five-year high in first quarter. (2026, April 1). Reuters. https://www.reuters.com/technology/tech-layoffs-2026-q1/
```

**In-text:**
```
(Metz, 2026)
("Tech Layoffs," 2026)
```

## Social media posts

APA 7 has explicit guidance for social media. Include the author's real name if known, then the screen name in brackets.

### Twitter/X posts

**Template:**
```
Last, F. [@username]. (Year, Month Day). Content of tweet up to 20 words [Tweet]. Twitter. URL
```

**Example:**
```
Obama, B. [@BarackObama]. (2020, July 30). Today, I'm excited to share some of the first folks who will receive support through the Obama Foundation's... [Tweet]. Twitter. https://twitter.com/BarackObama/status/1288854965514338304
```

### Facebook posts

```
Smithsonian Institution. (2025, June 12). Did you know that the Smithsonian has 19 museums? This summer, explore them all for free [Facebook post]. Facebook. https://www.facebook.com/Smithsonian/posts/123456789
```

### Instagram posts

```
NASA [@nasa]. (2025, April 22). Earth Day 2025: Our planet from space 🌍 [Photograph]. Instagram. https://www.instagram.com/p/abcdef/
```

**In-text citations for social media:**
```
(Obama, 2020)
(Smithsonian Institution, 2025)
(NASA, 2025)
```

## Online reports and government documents

These follow the webpage template but often include a report number.

**Example — government report:**
```
National Cancer Institute. (2025). SEER cancer statistics review 2025. U.S. Department of Health and Human Services. https://seer.cancer.gov/csr/2025
```

**Example — report with report number:**
```
Congressional Budget Office. (2025, March). The budget and economic outlook: 2025 to 2035 (Report No. 60699). https://www.cbo.gov/publication/60699
```

## Handling common problems

### The URL is very long

APA does not require shortening URLs. Paste the complete URL. If you are working in a word processor, hyperlink the URL rather than displaying it in full if your instructor permits.

### The page has been taken down

If you accessed the page while it was live, cite it as you found it. You may note "(Source no longer available)" after the URL, or include a Wayback Machine archive URL:

```
Author. (Year). Title. Website. https://web.archive.org/web/[timestamp]/original-url
```

### Multiple dates on the page (published and updated)

Use the most recent date that relates to the content itself (usually the "Updated" or "Last reviewed" date). If both published and updated dates are shown and relevant, you may use the updated date.

### The author's name is not clearly visible

Check the page footer, the "About" page, and the URL metadata. If no author can be identified, treat it as a no-author source and begin with the title.

## Quick reference: APA 7 website citation scenarios

| Situation | What comes first | Date field | In-text |
|-----------|-----------------|-----------|---------|
| Named author | Last, F. | (Year, Month Day) | (Last, Year) |
| Organization author | Full org name | (Year, Month Day) | (Org Name, Year) or abbreviation |
| No author | Page title in italics | (Year, Month Day) | (Shortened "Title," Year) |
| No date | Author | (n.d.) | (Author, n.d.) |
| Wiki / changing page | Author or org | (Year) + Retrieved date | (Author, Year) |
