## Setting Up Basic Monitoring

For most small websites, this free stack works:

1. **UptimeRobot** for basic HTTP monitoring
2. **Google Search Console** for crawl errors
3. **Our status checker** for ad-hoc diagnostics
4. **GTmetrix or PageSpeed Insights** for performance

## What to Monitor

- **HTTP status:** Is the server responding with 200 OK?
- **Response time:** Slow responses indicate problems before total downtime.
- **SSL certificate:** Expired certificates break sites.
- **Domain expiration:** Lapsed domains are embarrassing and costly.
- **Keyword presence:** Ensure your homepage still contains expected text.

## Interpreting Downtime

Not all downtime is equal:
- **1-5 minutes:** Likely a deployment or server restart. Usually harmless.
- **15-60 minutes:** Investigate hosting issues or traffic spikes.
- **1+ hours:** Major outage. Contact hosting provider immediately.

## Reducing Downtime

- Use a CDN like Cloudflare to absorb traffic spikes.
- Choose reliable hosting with 99.9%+ uptime SLA.
- Set up redundant DNS.
- Keep backups current and test restoration procedures.
- Monitor proactively rather than waiting for user complaints.
