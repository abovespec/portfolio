A QR code menu lets customers view your menu on their phones without handling a physical menu — useful for reducing clutter, cutting printing costs when you update prices, and speeding up table turns. Setting one up takes less than an hour and costs almost nothing.

## What to link the QR code to

You have three main options:

**1. A PDF of your menu**
Upload your menu PDF to your website or a file host (Google Drive, Dropbox). Copy the direct link and encode it. Simple, but updating the menu requires uploading a new file and, if the URL changes, regenerating the QR code.

For more on this topic, see [*QR Code for Website: Link Any Page to a Scannable Code*](/blog/qr-code-for-website).

**2. A webpage on your website**
Create a `/menu` page on your site. This is the most flexible option — update the page any time and the QR code never changes. It also lets you add photos, filtering by dietary preference, and ordering links.

For more on this topic, see [*How to Create a QR Code: A Complete Beginner's Guide*](/blog/how-to-create-a-qr-code).

**3. A third-party menu platform**
Services like Square, Toast, or Canva's menu builder generate a shareable URL. Encode that URL. The tradeoff: you're dependent on the platform's uptime and branding.

**Recommendation:** Use a URL on your own website if you have one. If not, a PDF upload to a stable URL (your existing hosting) is reliable and free.

## Step-by-step: creating the menu QR code

1. Get your menu URL — either a PDF link or a webpage URL.
2. Go to [QR code generator](/) and enter the URL.
3. Choose **error correction level H (30%)** if you plan to add a logo, or **M (15%)** for a clean, dense code.
4. Download as SVG (for professional printing) or high-resolution PNG (minimum 1000 × 1000 px for print).
5. Place the QR code in your table tent, menu card, or signage design.
6. Print a test copy and scan with both iPhone and Android before printing in quantity.

For more on this topic, see [*QR Code Size Guide for Printing: Minimum Sizes, DPI, and Scan Distance*](/blog/qr-code-size-guide-for-printing).

## Sizing for print

| Placement | Minimum size | Typical scan distance |
|-----------|-------------|----------------------|
| Table tent (A-frame) | 3 × 3 cm (1.2 in) | 20–30 cm |
| Tabletop sticker | 4 × 4 cm (1.6 in) | 20–40 cm |
| Wall-mounted sign | 8 × 8 cm (3.1 in) | 60–80 cm |
| Window / door | 12 × 12 cm (4.7 in) | 1–1.5 m |

Always include a quiet zone (white margin) of at least 4 module widths on all sides. Never let design elements bleed into the QR code itself.

**DPI for print:** Use 300 DPI minimum. SVG format is preferable for print because it scales infinitely without quality loss. If you use PNG, ensure the file is at least 1000 × 1000 px before scaling down to print size.

## Table placement best practices

**Eye level and accessible.** Place the QR code where it's visible when a customer sits down — on a table tent at 15–20 cm height, or on the tabletop itself under a protective laminate.

**Avoid glare.** Glossy laminated cards in direct window light can create glare that makes scanning harder. Use matte lamination for tabletop QR codes when possible.

**One code per table.** Don't crowd the table with multiple QR codes (WiFi, review, menu, ordering). If you need multiple, use a well-spaced card that labels each one clearly.

**Include a short instruction.** Print "Scan for menu" or "Scan to view our menu" next to the code. Include a fallback: "Ask your server for a printed menu" for guests who prefer it.

## Keeping the menu current

The biggest advantage of a QR code menu over printed menus is instant updates. Plan for this:

- **Use a stable, permanent URL.** Avoid URLs that include version numbers or dates (e.g., `/menu-v3.pdf`). Use `/menu` or `/menu.pdf` so you can swap the file without changing the URL.
- **Update the PDF or page, not the QR code.** If the URL never changes, your printed QR codes stay valid indefinitely.
- **Test after every update.** After uploading a new menu, scan the QR code from a fresh browser session to confirm the new version loads.

## What to put on the menu page

Beyond the menu itself, consider adding:

- **Allergen and dietary filters** (vegan, gluten-free, nut-free) — reduces server questions
- **Photos** for high-margin items — research consistently shows photos increase item orders
- **Current specials** — the page can be updated daily without reprinting
- **Ordering link** — if you use an online ordering platform, include a button
- **Hours and address** — useful when customers share the link with friends

## Common mistakes

**Linking to a file that requires a login.** If you upload to Google Drive, ensure the sharing is set to "Anyone with the link." Test it in a private/incognito browser window before printing.

**Using a URL shortener with expiry.** Some free link shorteners expire after a period. Use your own domain or a permanent shortener.

**Printing at too small a size.** A QR code smaller than 2.5 cm (1 in) on a table is frustrating to scan and reflects poorly on the experience. Size up.

**No fallback.** Always give guests an alternative if scanning fails — a server, a chalkboard menu, or a small printed card.
